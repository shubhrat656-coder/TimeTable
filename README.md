# TimeTable

A responsive weekly timetable web app. One page, no framework and no build step —
plain HTML, CSS and JavaScript.

## Files

| File | Purpose |
| --- | --- |
| `file.html` | Page structure and the timetable grid |
| `styles.css` | Layout, colour and responsive rules |
| `script.js` | Timetable data and rendering logic |
| `cms logo.png` | Logo shown in the header |

## Running

Open `file.html` in any browser. There is nothing to install.

## Notes

The layout adapts to narrow screens, so the grid stays readable on a phone.
